Restricts deployments during specific time windows unless authorized.

Usage:
  deploymentPolicy()

Environment Variables:
  - AUTHORIZED_DEPLOYERS: JSON array of usernames allowed to deploy (e.g., '["salman", "user2", "user3"]')
  - AUTHORIZED_DEPLOYER_TOKEN: Secret key used to validate authorized users
  - DEPLOY_RESTRICTION_START: Deployment restriction start time (e.g., 1045)
  - DEPLOY_RESTRICTION_END: Deployment restriction end time (e.g., 1200)

Methods:
  - deploymentPolicy(): Enforces deployment time and user restrictions.

Notes:
  - Uses Jenkins server default time zone.
  - Authorized users bypass time restrictions.
