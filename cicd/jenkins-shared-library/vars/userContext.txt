Provides information about the current build user and system context.

Usage:
  echo "Built by ${userContext.triggerUser.name} <${userContext.triggerUser.email}>"
  echo "Admin Email: ${userContext.systemUser.name} <${userContext.systemUser.email}>"

  echo "==== User Context Loop ===="
  def ctx = userContext()
  ctx.each { k, v -> echo "${k}: id=${v.id}, user=${v.name}, email=${v.email}" }

Properties:
  - userContext(): Returns a map containing user context information.
  - userContext.triggerUser.{id, name, email}: Details of the user who triggered the build.
  - userContext.commitAuthor.{id, name, email}: Details of the commit author (if applicable).
  - userContext.systemUser.{id, name, email}: Details of the Jenkins system user.

Notes:
  - Works with both manually triggered and SCM-triggered builds.
  - Can be used in shared libraries or directly in pipeline scripts.
